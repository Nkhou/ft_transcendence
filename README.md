📋 Overview

ft_transcendance is a full-stack web application featuring a real-time multiplayer Pong game with integrated chat, user profiles, and authentication. The project combines modern web technologies to create an engaging online gaming experience with social features.
✨ Features

Real-time Multiplayer Pong - Challenge friends or random players to classic Pong matches
Live Chat System - Public channels, private messages, and in-game chat
User Authentication - Secure login with OAuth 2.0 and two-factor authentication
Profile Customization - Avatar uploads, stats tracking, and friend management
Matchmaking System - Find opponents based on skill levels
Responsive Design - Seamless experience across desktop and mobile devices
